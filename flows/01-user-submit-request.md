# User / Client — Submitting a Request

## Happy Path

**Step 1 — Sign up & log in**
Create an account (choose your Position), then log in.

> 📸 _Screenshot here_

**Step 2 — Complete your profile (first time only)**
Go to **Profile** and add your **signature**. This is required so your name and signature appear on the generated request form.

> 📸 _Screenshot here_

**Step 3 — Go to New Request**
Open **Requests → New Request**.

> 📸 _Screenshot here_

**Step 4 — Fill up the form**
Enter the title, type of request, priority, details, justification, work scope, and attach any supporting files.

> 📸 _Screenshot here_

**Step 5 — Save as Draft (optional)**
You can click **Save as Draft** to finish it later.

> 📸 _Screenshot here_

**Step 6 — Submit**
Click **Submit**. The system assigns a **Document Number** (e.g. `2026-0001`) and the status becomes **Submitted**.

> 📸 _Screenshot here_

**Step 7 — Track the status**
On your dashboard you'll see the request as **Submitted**.

> 📸 _Screenshot here_

## Alternate / Worst Paths

**A — Returned by IDO**
If IDO returns your request, the status becomes **Returned by IDO**. Open it, read the note,
fix the form, and **Submit again** (keeps the same document number).

> 📸 _Screenshot here_

**B — Rejected by IDO**
Status becomes **Rejected by IDO**. This is final — the request stops here. File a new one.

> 📸 _Screenshot here_

**C — Deferred (For Next Year PPMP)**
Status becomes **For Next Year PPMP**. Your request is valid, but there is no budget this
year, so it is set aside for next year's procurement plan.

> 📸 _Screenshot here_

**D — Rejected later (Budget / Director / Final)**
If a later approver rejects it, the status shows who rejected it and the request stops there.

> 📸 _Screenshot here_
