# IDO Officer / IDO Chairperson — First Review

> This is the first checkpoint. Both the **IDO Officer** and the **IDO Chairperson** can do it.

## Happy Path

**Step 1 — Log in and open the Dashboard**
Go to the **Dashboard**, which lists all **Submitted** requests.

> 📸 _Screenshot here_

**Step 2 — Open a request**
Click a request to read its details and attachments.

> 📸 _Screenshot here_

**Step 3 — Set final title / reference (optional)**
Optionally set the **Final Title** and add a **reference or note**.

> 📸 _Screenshot here_

**Step 4 — Recommend**
Click **Recommend**. The request moves forward:
- If a **Budget Officer** exists → it goes to the **Budget Officer** next.
- If none → it goes straight to **Director Review**.

> 📸 _Screenshot here_

---

## Alternate / Worst Paths (same screen)

**A — Return to Requestor**
Click **Return**, add a note. Status becomes **Returned** and the user can edit & resubmit.

> 📸 _Screenshot here_

**B — Reject**
Click **Reject**, add a note. Status becomes **Rejected by IDO** (final).

> 📸 _Screenshot here_

**C — Defer to Next Year PPMP**
Click **Defer to Next Year PPMP**, add a note. Status becomes **For Next Year PPMP**
(valid request, but no budget this year).
